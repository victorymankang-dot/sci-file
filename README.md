# sm-morning-briefing — 사이언스모니터 아침 편집 브리핑 스킬

과학기술 전문 매체 [사이언스모니터](https://scimonitors.com)의 편집장이 **매일 아침 AI에게 반복해서 시키던 "오늘 쓸 기사 후보 찾기"** 를 한마디로 끝내기 위해 만든 Claude Code 스킬입니다.

## 불편 → 해결

| 매일 겪던 불편 | 스킬로 바꾼 것 |
|---|---|
| 매일 아침 "AI·양자·정책·과학 소식 찾아서, 출처 붙이고, 표로…"를 **긴 프롬프트로 다시 썼다** | **"오늘 브리핑"** 한마디로 같은 절차가 실행된다 |
| 월요일엔 주말 소식이 빠졌다 (24시간만 찾음) | 월요일은 자동으로 **72시간** 범위 |
| 이미 우리 사이트에 쓴 주제가 후보로 또 올라왔다 | `site:scimonitors.com` 검색으로 **중복 주제 자동 제외** |
| 링크 없는 후보, 출처 불명 소식이 섞였다 | **원문 링크 없는 후보는 넣지 않음** + "확인 필요" 목록 분리 |
| 날마다 결과 형식이 달라 비교·판단이 느렸다 | **표 하나 + 오늘의 추천 2~3건** 고정 형식 |
| AI가 후보를 찾다가 기사까지 써버렸다 | **후보 선정까지만**. 본문 작성·발행은 하지 않음 |

## 설치

```
<내 프로젝트>/.claude/skills/sm-morning-briefing/SKILL.md
```
이 저장소의 `.claude` 폴더를 프로젝트 루트에 복사하면 됩니다.
(전체 프로젝트에서 쓰려면 `~/.claude/skills/sm-morning-briefing/SKILL.md`)

## 사용법

새 대화에서 한마디만 입력합니다.

```
오늘 브리핑
```
다른 표현도 발동합니다: `아침 브리핑`, `편집 브리핑 만들어`, `오늘 뭐 쓸까`

결과 예시 구조:
```
## 오늘의 추천 (2026-11-03)
1. [가제] — 속보 — 추천 이유
2. [가제] — 해설 — 추천 이유
```

## 배경

사이언스모니터는 하루 2건(속보 1 + 해설 1) 발행을 목표로 합니다. 기사 후보 찾기는 매일 반복되지만 절차는 늘 같았습니다 — 분야별 출처 확인 → 중복 제외 → 링크 확인 → 표 정리 → 추천. 이 고정 절차를 스킬로 묶어 매일 아침의 프롬프트 작성 시간을 없앴습니다.
